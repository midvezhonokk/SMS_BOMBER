1) ВЫНЕСЕН СЕКРЕТЫ В .env 
------------------------------------
Проблема: токен бота, ID админов, ключи Qiwi лежали в исходнике

Что сделал:
  - Создал файл .env со всеми секретами.
  - Создал cfg.py — единая точка чтения настроек
    (TOKEN, ADMIN_CHAT_ID, YOOKASSA_*, PRICE и т.д.).
  - В main.py импорты заменены: cfg.token -> cfg.TOKEN,
    хардкод ID -> cfg.ADMIN_CHAT_ID и т.д.
  - price, THREADS_LIMIT, VIP_DAYS теперь тоже из .env.

Установка: pip install python-dotenv


2) ЗАМЕНА QIWI НА ЮKASSA
---------------------------------
Проблема: Qiwi ушла из РФ в 2024, edge.qiwi.com мёртв,
выпуск API-токенов остановлен.

Что сделал:
  - Создал payment.py — модуль оплаты через ЮKassa.
  - Pull-модель (опрос истории платежей) заменена на
    push-модель (вебхуки от ЮKassa).
  - Реализовано:
      * create_payment_link(chat_id) — создаёт платёж,
        возвращает ссылку на оплату.
      * /yookassa-webhook — Flask-эндпоинт, принимает
        payment.succeeded.
      * Проверка подписи через SDK yookassa.
      * Идемпотентность: повторный вебхук не выдаёт
        VIP дважды.
      * chat_id передаётся через metadata, а не через
        комментарий к платежу.
  - Старая функция donat() и блок с qiwi_token/qiwi_phone
    удалены.
  - В main.py добавлены:
      payment.setup(bot, add_vip)
      payment.start()
  - Кнопка "▪️Купить доступ▪️" теперь создаёт платёж и
    показывает inline-кнопку с ссылкой.

Установка: pip install yookassa flask
Настройка: в личном кабинете ЮKassa указать URL вебхука
           (нужен HTTPS, локально — ngrok).


3) ЛОГИРОВАНИЕ ВМЕСТО PRINT
------------------------------------
Проблема: print() по всему коду — без времени, уровня,
источника, без записи в файл. Не видно, что реально
работает, а что падает.

Что сделал:
  - Создал logger.py (общий логгер)
  - Пишет одновременно в консоль (INFO+) и в
    logs/bot.log с ротацией (5 МБ × 3 файла, DEBUG+).
  - Формат: время | уровень | модуль | сообщение.
  - В main.py добавлен import: from logger import log.
  - Ключевые print заменены:
      print(...)           -> log.info(...)
      print("[-] ...")     -> log.debug(...)
      print("Макс. тредов")-> log.warning(...)
      print(e) в except    -> log.exception(...)

ВАЖНО: массовая замена print на log.debug через sed
НЕ рекомендуется — легко сломать многострочные вызовы.
Лучше вручную или через IDE.

Просмотр логов:
  Linux/macOS:   tail -f logs/bot.log
  Windows:       Get-Content logs/bot.log -Wait -Tail 20
